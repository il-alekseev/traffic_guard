# Программа и методики испытаний сервиса tg-etl

## Введение

В данном разделе тестируется имплементация и взаимодействие сервиса tg-etl с внешними системами и внутренними компонентами:

- Базы данных (KSU PostgreSQL, ETL PostgreSQL)
- Apache Kafka
- UserControl сервис
- Keycloak
- Обработка IDS логов
