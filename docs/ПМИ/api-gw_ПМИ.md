# Программа и методики испытаний сервиса api-gw

## Введение

В данном разделе тестируется имплементация и взаимодействие сервиса `api-gw` с внутренними сервисами проекта:
- `usercontrol`
- `ctxcontrol`
- `blog`
- `analytics`

Проверяется корректность маршрутизации запросов, обработка успешных и ошибочных сценариев взаимодействия с бэкенд-сервисами, а также соответствие формату логирования.

---
