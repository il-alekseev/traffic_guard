# Программа и методики испытаний сервиса tg-analytics

## Введение

В данном разделе тестируется функциональность микросервиса tg-analytics, который предоставляет аналитическую информацию для фронтенда системы Traffic Guard. Тестируются основные endpoints API, обработка данных и интеграция с базами данных.

---

## Методика проведения испытаний

### 1. Подготовка тестового окружения

```bash
# Запуск зависимостей
docker-compose up -d 

```

### 2. Запуск тестов

```bash

# Выполнение API тестов
./run_api_tests.sh

# Мониторинг логов
watch docker logs --tail 40 tg-an
```

### 3. Тестовые сценарии

```bash
# Тест получения сессий
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost:7000/api/v1/sessions?from=now-1h&to=now&page=1&limit=10"

# Тест создания отчета
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost:7000/api/v1/reports?from=now-24h&to=now"

# Тест действия над доменом
curl -X PATCH -H "Authorization: Bearer $TOKEN" \
  "http://localhost:7000/api/v1/detections/act?action=allow&path=example.com"
```

### 4. Критерии успешности

- Все endpoints возвращают ожидаемые HTTP статусы
- Данные корректно фильтруются и сортируются
- Пагинация работает корректно
- Ошибки обрабатываются грациозно
- Производительность отвечает требованиям
- Ролевая модель соблюдается

### 5. Мониторинг во время тестирования

- Логирование запросов и ошибок
- Метрики производительности API
- Использование памяти и CPU
- Время ответа БД
- Количество одновременных подключений
